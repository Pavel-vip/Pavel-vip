# Pavel-vip

Личная экосистема для работы в сфере продаж, маркетинга и таргета.

## Фокус

**Авито** — первое и основное направление. Рабочий цикл:

1. **Анализ** — быстро и качественно разбирать категорию: спрос, конкуренты, цены, ниши.
2. **Запуск** — быстро собирать и публиковать карточки товара, которые продают.
3. **Масштабирование** — реклама, бюджеты, метрики: что работает — усиливаем, что нет — отключаем.

## Структура репозитория

```
Pavel-vip/
├── avito/
│   ├── analysis/    # Готовые разборы категорий (по одному файлу на разбор)
│   ├── cards/       # Карточки товаров: запуск и работающие объявления
│   └── scaling/     # Недельные отчёты, бюджеты рекламы, решения по масштабированию
└── templates/
    ├── avito-analysis.md   # Шаблон разбора категории
    ├── avito-launch.md     # Шаблон запуска карточки
    └── weekly-report.md    # Шаблон недельного отчёта
```

## Как этим пользоваться

**Анализ**
Берёте шаблон `templates/avito-analysis.md` → копирование в `avito/analysis/YYYY-MM-DD-название-категории.md` → заполняете по чек-листу → в «Вывод» фиксируете go/no-go.

**Запуск**
Берёте `templates/avito-launch.md` → файл в `avito/cards/` → готовите заголовок, описание, цены, чек-лист фото → публикуете → через 3 дня фиксируете первые метрики.

**Масштабирование**
Раз в неделю — файл в `avito/scaling/` по шаблону `templates/weekly-report.md`: метрики по карточкам, что работает / что нет, план на следующую неделю.

## Работа в AI Arena

Просто просите в чате, например:

- «Проанализируй категорию X по шаблону» — соберу структуру разбора.
- «Напиши заголовки и описание для карточки Y» — сделаю по шаблону запуска.
- «Составь недельный отчёт: вот цифры …» — оформлю отчёт.

Все изменения вносятся в отдельную ветку и после одобрения (PR) попадают в `main` — история всех решений сохраняется в Git.
